# КИБЕА — уебсайт на студио за масажи и натурална козметика

Одностраничен (one-page) уебсайт за **студио КИБЕА** в Пловдив: представяне на студиото, ритуали и масажи, галерия, отзиви от Google, контакти и директна връзка за запазване на час.

Сайтът е написан на чист **HTML, CSS и JavaScript** — без framework и без стъпка за билд.

## Основни възможности

- **Hero секция** с призив за запазване на час и работно време
- **„За КИБЕА“** — кратко представяне на студиото
- **„Нашите ритуали“** — карти със снимки (авторски масаж, лимфен дренаж, тай масаж на лице, ароматерапия, вулканични камъни, енергийни практики, лимфен дренаж на корем), всяка с бутон „Запази“
- **Галерия „Атмосфера“** — снимки на пространството и терапиите
- **Отзиви** — реални Google отзиви и бутон **„Оцени ни в Google“**, който води директно към формата за писане на отзив в профила на студиото
- **Запазване на час** през [Studio24](https://studio24.bg/m/studio-za-masazhi-i-naturalna-kozmetika-kibea-s3537)
- **Контакти** — телефон, адрес, Instagram, Facebook, работно време и вградена Google карта
- Адаптивен дизайн (десктоп, таблет, телефон) с мобилно меню
- Хедър, който променя вида си при скрол; поддръжка на `prefers-reduced-motion`

## Структура на проекта

```
.
├── index.html      # цялото съдържание на страницата
├── style.css       # стилове и адаптивност
├── script.js       # мобилно меню, хедър при скрол, текуща година във футъра
├── images/
│   ├── logo.jpg        # лого (хедър и favicon)
│   ├── secondLogo.jpg  # лого в секция „Контакти“
│   ├── 1.jpg … 5.jpg   # снимки за hero, „За КИБЕА“, галерия
│   ├── 3.jpg           # авторски масаж

```

> Снимките се четат от папка `images/`. Ако ги качиш другаде, промени пътищата в `index.html`.

## Стартиране локално

Не е нужна инсталация. Достатъчно е да отвориш `index.html` в браузър.

По желание, с малък локален сървър:

```bash
# Python
python3 -m http.server 8000
# после отвори http://localhost:8000
```

## Публикуване в GitHub Pages

1. Качи проекта в GitHub хранилище.
2. Отвори **Settings → Pages**.
3. В **Source** избери клона `main` и папка `/ (root)`.
4. След минута сайтът е достъпен на `https://<потребител>.github.io/<хранилище>/`.

## Как се променя съдържанието

| Какво | Къде |
|---|---|
| Ритуали (заглавие, описание, снимка) | `<article class="ritual-card">` в секция `#services` |
| Отзиви | `<article class="review-card">` в секция `#reviews` |
| Работно време | блока `.hours` в секция `#contact` |
| Телефон, адрес, социални мрежи | `.contact-list` в секция `#contact` |
| Цветове и шрифтове | CSS променливите в `:root` в началото на `style.css` |
| Линк за запазване на час | всички линкове към `studio24.bg` в `index.html` |

### Бутон „Оцени ни в Google“

Бутонът използва Google Place ID на студиото:

```
https://search.google.com/local/writereview?placeid=ChIJ_3Tt-23RrBQRGH5BTl3J-fQ
```

Ако профилът на студиото се смени, намери новия Place ID през [Place ID Finder](https://developers.google.com/maps/documentation/places/web-service/place-id) и го замени в линка (клас `.review-cta` в `index.html`).
